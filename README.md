# SallaPush Flutter, React Native and Capacitor SDKs

Push notifications for the Flutter, React Native and Capacitor apps of Salla stores.

> **SallaPush is for the mobile apps of Salla stores.** Contact the Salla team for your app id.

Each package lives in a folder of its own, with its own README, changelog and releases:

| Package | Install | Docs |
|---|---|---|
| Flutter | `flutter pub add mobile_push` | [flutter/README.md](flutter/README.md) |
| React Native and Expo | `npx expo install @salla.sa/mobile-push-react-native` in an Expo app, or `npm install @salla.sa/mobile-push-react-native` in a bare React Native app | [react-native/README.md](react-native/README.md) |
| Capacitor | `npm install @salla.sa/mobile-push-capacitor`, then `npx cap sync` | [capacitor/README.md](capacitor/README.md) |

Then follow the package's README for the platform setup and a quick start.

**Native SDKs:** [SallaPush iOS](https://github.com/SallaApp/mobile-push-ios-sdk) ·
[SallaPush Android](https://github.com/SallaApp/mobile-push-android-sdk)

## Support

- **SDK bugs and feature requests:** [open an issue](https://github.com/SallaApp/mobile-push-sdk/issues/new/choose),
  choose the package, and give the SDK, framework and OS versions and the SallaPush log codes you saw. Never paste
  tokens, keys or customer data.
- **App ids:** Contact the Salla team for your app id.
